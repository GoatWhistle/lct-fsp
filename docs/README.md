# Документация calibr

> calibr — платформа подбора ИТ-специалистов с обратной механикой. Кандидат получает категорию —
> специализация × грейд — только адаптивным тестом и профиль навыков с погрешностью по каждой
> теме; работодатель получает подборку из подтверждённой категории с объяснением каждого места и
> сам приглашает кандидата с вилкой зарплаты. Здесь — как это устроено, почему именно так, как
> проверено и как запускается.

**Начните здесь, если вы в жюри:** [маршрут для жюри](for-jury.md) — 18 шагов по стенду и где в
репо ответ на каждый критерий оценки. Обзор продукта — [README проекта](../README.md).
