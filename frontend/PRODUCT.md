# calibr

Платформа подбора ИТ-специалистов для Федерации спортивного программирования России. Позиционирование —
подбор по подтверждённому тестом уровню, а не по резюме: категорию кандидата определяет только адаптивный тест, а не резюме.

## Для кого

- **Кандидат** проходит опрос, выбирает грейд, сдаёт адаптивный тест и получает категорию
  (специализация и грейд) и профиль навыков: уровень и погрешность по каждой теме. Достижения ФСП
  подтягиваются по ФСП ID и весят больше всего. Кандидат получает приглашения с вилкой, отвечает на
  регулярные задания, откликается на вакансии.
- **Работодатель** описывает потребность мастером или словами, получает подборку с объяснением по темам и
  вероятностью принятия, сравнивает кандидатов и сам отправляет приглашение с вилкой. До принятия
  приглашения карточка кандидата обезличена.

## Регистр

Продукт, а не лендинг: рабочие экраны кабинета, которые открывают десятки раз за день. Главная страница —
единственный экран в регистре бренда.

## Тон

Коротко и глаголами, без маркетинга. «Уровень», «погрешность», «подтверждено тестом», «вероятность» —
без «θ», «σ», «система поняла». Два языка, RU по умолчанию и EN полностью (в EN — FSP).

## Ключевые экраны

Тест кандидата, раскрытие категории, обзор кандидата, мастер потребности, подборка, карточка кандидата,
приглашения и переписка.
