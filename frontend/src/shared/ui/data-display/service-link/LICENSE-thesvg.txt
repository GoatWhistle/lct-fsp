Service brand glyphs in service-glyphs.ts

Source: theSVG - https://github.com/glincker/thesvg
Retrieved: 2026-08-29, from public/icons/<slug>/mono.svg
(LinkedIn has no mono variant and was taken from public/icons/linkedin/default.svg).

Only the 66 marks the company links can display were taken into the
repository, not the upstream set of 6500+ icons. Each mark was reduced to its
single path and recoloured to currentColor so it follows the interface theme;
the path geometry itself is unchanged.
