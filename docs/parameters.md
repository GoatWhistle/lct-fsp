# Параметры механик по умолчанию

Единственный источник чисел механик. Код берёт значения из конфига **под этими же именами**;
смена значения — правка этой таблицы и конфига в одном PR, с причиной в описании. Что параметр
делает и почему значение такое — в [mechanics.md](mechanics.md), раздел указан в колонке «§».

Пороги метрик, сиды и доли персонажей стенда валидации — не настройки продукта, они живут в
[validation-plan.md](validation-plan.md).

Единицы: θ — логиты шкалы уровня; доли — от 0 до 1. «Подбирается на настроечном наборе» значит,
что значение выбирается до прогона на отдельном сиде по правилу из плана валидации.
