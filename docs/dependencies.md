# Зависимости

Библиотеки и компоненты с версиями и лицензиями. Версии — те, что закреплены в lock-файлах
`backend/uv.lock` и `frontend/package-lock.json` и в образах `docker-compose.yml`. Всё — открытое
ПО под разрешительными лицензиями; копилефт только слабый (LGPL, MPL), подключается библиотекой
без изменений.
