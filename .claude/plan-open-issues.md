## Правило закрытия

Закрывать issue после проверки всех его критериев и записи итогового доказательства в issue или PR. Наличие похожей функции в коде само по себе не считается выполнением. Для человеческих проверок приложить протокол/разметку; для экспериментальных утверждений — отчёт стенда по заранее зафиксированному плану. Закрытые PR проверять на `merged`: закрытый без merge PR не подтверждает попадание изменений в `main`.
