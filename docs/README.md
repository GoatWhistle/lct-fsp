# Документация

- [mechanics.md](mechanics.md) — как работают тест, профиль навыков, подбор и рынок, по каким
  формулам и почему так.
- [parameters.md](parameters.md) — числа механик по умолчанию под именами из конфига.
- [threat-model.md](threat-model.md) — угрозы, защита, остаточный риск и эксперимент на каждую.
- [validation-plan.md](validation-plan.md) — метрики, данные, базовые линии и пороги;
  зафиксирован до прогона стенда валидации.
- [validation-report.md](validation-report.md) — отчёт валидации по плану: значение, порог и
  вердикт каждой метрики на D1 и D2; собирается командой стенда, руками не правится.
- [glossary.md](glossary.md) — термины и их имена в коде.
- [adr/](adr/) — архитектурные решения: что решено, почему и какие варианты отклонены.
